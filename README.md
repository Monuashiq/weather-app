# 🌤 **Weather App**

## 📌 **Project Title**
**Weather App**

## 👨‍💻 **Role**
**Fullstack Developer (Node.js – React – MongoDB)**

## 📝 **Description**
A mobile-friendly weather application that fetches real-time weather information from the **OpenWeatherMap API**, stores the data in a **MongoDB** database, and presents it in a clean, user-friendly interface. It also includes a historical weather data section with filters by **location** and **date range**.

---

## 🚀 **Key Features**

- 🔍 **Fetch Weather Data** from OpenWeatherMap (temperature, description, icon)
- 📱 **Mobile-Responsive UI** built with React & Tailwind CSS
- 🗂 **Historical Weather Data Storage** in MongoDB
- 📆 **Filter by Location and Date Range** (Max range: 30 days)
- ❗ **Error Handling & Input Validation** included
- 🌍 Supported Locations: **Delhi, Moscow, Paris, New York, Sydney, Riyadh**

---

## 🧰 **Tech Stack**

| Layer       | Technology           |
|-------------|----------------------|
| Frontend    | React, Tailwind CSS  |
| Backend     | Node.js, Express.js  |
| Database    | MongoDB              |
| API         | OpenWeatherMap       |
